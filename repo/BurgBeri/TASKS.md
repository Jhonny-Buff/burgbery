# Задачи по проекту "Бургбери"

## Обзор проекта
Воссоздание и доработка сайта доставки еды "Бургбери" (г. Ейск) с добавлением админ-панели и системы управления заказами.

---

## Часть 1: Воссоздание существующего сайта

### 1.1 Основной сайт (клиентская часть)
- **Header**: Логотип, навигация (Главная, Новинки, Меню, Оплата и доставка, Акции), контакты (+7 918 177 20 33, г. Ейск, ул. Плеханово, д. 15/4), кнопка корзины
- **Hero баннер**: Привлекательное изображение с текстом "Вкус, который вы полюбите", кнопки "Смотреть меню" и "Акции"
- **Карточки товаров**: Изображение, название, описание, вес, цена, кнопка добавления в корзину
- **Модальное окно товара**: Детальная информация, состав, кнопка добавления
- **Страница меню**: Категории (Роллы, Сеты, Пицца, Лапша ВОК, Бургеры, Сандвичи, Шаурма, Морепродукты, Ланч боксы, Закуски, Соусы, Десерты и напитки, Наборы, Салаты), фильтрация товаров
- **Страница новинок**: Отображение новых позиций меню
- **Страница акций**: Карточки акций и спецпредложений
- **Страница доставки**: Информация о доставке, оплате, режиме работы, адресе
- **Карта**: Яндекс карта с местоположением ресторана
- **Footer**: Контакты, ссылки, соцсети, вакансии

### 1.2 Корзина
- Боковая панель (slide-out)
- Список добавленных товаров с изображениями
- Изменение количества (+/-)
- Удаление товаров
- Отображение итоговой суммы
- Кнопка "Оформить заказ"

## Часть 2: Форма оформления заказа

### 2.1 Поля формы (согласно скриншоту 1)
| Поле | Тип | Описание |
|------|-----|----------|
| Ваше имя | Текст | Имя клиента |
| Номер телефона | Телефон | Контактный номер |
| Варианты доставки | Радио-кнопки | Курьером / Самовывоз |
| Адрес доставки | Textarea | Отображается только при выборе "Курьером" |
| Способ оплаты | Радио-кнопки | Наличными / Банковской картой |
| Количество приборов | Число | Количество комплектов приборов |
| Промокод | Текст | Опционально, для скидок |

### 2.2 Защита от ботов
- Интеграция CAPTCHA (Google reCAPTCHA или аналог)
- Проверка перед отправкой формы

### 2.3 Валидация
- Обязательные поля: имя, телефон, способ доставки, способ оплаты
- Формат телефона: российский (+7...)
- Адрес обязателен при выборе курьерской доставки

---

## Часть 3: Админ-панель

### 3.1 Аутентификация
- Логин/пароль для администратора
- Защищенные маршруты админ-панели

### 3.2 Управление категориями еды
- Просмотр списка категорий
- Добавление новой категории (название, сортировка)
- Редактирование категории
- Удаление категории (с проверкой на наличие товаров)

### 3.3 Управление позициями меню
- Просмотр списка товаров (с фильтрацией по категории)
- Добавление нового товара:
  - Название
  - Описание (краткое и полное)
  - Цена
  - Вес
  - Категория
  - Состав/ингредиенты
  - Изображение (URL или загрузка)
  - Статус (активен/скрыт)
- Редактирование товара
- Удаление товара

### 3.4 Система обработки заказов (согласно скриншоту 2)
- **Список заказов** с колонками:
  - ID заказа
  - Имя клиента
  - Номер телефона
  - Дата и время заказа
  - Сумма заказа
  - Статус
  - Действия

- **Статусы заказов**:
  - 🟡 **Ожидает** (pending) - новый заказ, ожидает обработки
  - 🔵 **Подтверждаем** (processing) - в процессе подтверждения (опционально)
  - 🟢 **Подтвержден** (confirmed) - заказ подтвержден
  - 🔴 **Отменена** (cancelled) - заказ отменен

- **Фильтрация**:
  - По статусу (выпадающий список "Все статусы")
  - Поиск по имени или номеру телефона

- **Действия с заказом**:
  - Просмотр деталей заказа
  - Изменение статуса
  - Удаление заказа

- **Детали заказа**:
  - Информация о клиенте
  - Список заказанных товаров
  - Способ доставки и адрес
  - Способ оплаты
  - Количество приборов
  - Примененный промокод
  - История изменений статуса

## Часть 4: База данных клиентов

### 4.1 Хранение данных клиентов
- Имя
- Номер телефона (уникальный идентификатор)
- Дата первого заказа
- Количество заказов
- Общая сумма заказов
- Статус (обычный / в черном списке)

### 4.2 Просмотр клиентов в админке
- Таблица со всеми клиентами
- Поиск по имени/телефону
- История заказов клиента
- Общая статистика

---

## Часть 5: Черный список

### 5.1 Функционал
- Добавление клиента в черный список по номеру телефона
- Удаление из черного списка
- Причина добавления (опционально)
- Дата добавления

### 5.2 Ограничения для заблокированных
- При попытке оформить заказ с заблокированного номера - отказ с сообщением
- Отображение индикатора в списке клиентов

## Техническая реализация

### База данных (PostgreSQL)
**Таблицы:**
- `categories` - категории еды
- `products` - позиции меню
- `orders` - заказы
- `order_items` - позиции в заказе
- `customers` - клиенты
- `blacklist` - черный список
- `admins` - администраторы

### Стек технологий
- **Frontend**: React, Tailwind CSS, Shadcn UI
- **Backend**: Express.js, PostgreSQL
- **Формы**: React Hook Form + Zod валидация
- **Капча**: Google reCAPTCHA v2 или v3
